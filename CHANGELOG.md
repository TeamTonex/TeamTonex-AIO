# Changelog

## 1.0.0

First public release.

- Bags, Clothing, Vests, Sign and Vehicles studios.
- Emergency lights: draw a line on the car to get light sets made for it, LED strips that follow the body, ready-made sets, and siren bones added to cars without them.
- Mods tab: any gta5-mods.com mod or downloaded file turned into a FiveM resource, with smaller textures.
- Updates from GitHub with one-click install, checked every 30 minutes or from Settings.
